```

【参数 ↔ 配图对应表】（核心，必填）

【逐段内容要求】
1. 段落1（配图：图1）：围绕xxx写3-4句，突出…
2. 段落2（配图：图2,图3）：把参数表讲清楚，强调达标…
（不会写文案就写"AI按参数发挥"，我来起草你改）
```

## 给图的三种方式
1. 放文件夹 + 编号命名（`图1-外观.jpg`）→ 最省事，直接读。
2. 对话里直接上传图片，说明"第N张对应第X段"。
3. 图未出、只有占位需求 → 写"此处需图：原理示意图"，先留白版式，你后补。

## 一次成稿的三条建议
- 先给一页"范例"对齐风格：旧文档/截图给我，我照其版式复刻。
- 参数用表格给，别揉进句子。
- 一次给全，不分批。
